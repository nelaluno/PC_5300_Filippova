# PC_5300 — Parallel Computing

Coursework from the Parallel Computing course (PC 5300) at Saint Petersburg
State Electrotechnical University (ETU "LETI"), completed as part of a
Master's programme in Computer Science and Knowledge Discovery.

## Structure

Each homework assignment is developed in its own branch. To explore a specific
assignment, switch to the corresponding branch:

```bash
git checkout hw1   # Homework 1
git checkout hw2   # Homework 2
```

A full list of branches is available under the
[Branches](../../branches) tab.

## Topics covered

- Parallel algorithm design and analysis
- Thread synchronisation and data races
- Performance measurement and speedup analysis
- Practical implementations using Python / C++ threading primitives

## Context

Exercises focus on translating sequential algorithms into parallel equivalents
and measuring real-world performance gains across different concurrency models.
